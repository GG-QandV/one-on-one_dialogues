# E3 — живые карточки перевода

| | |
| :-- | :-- |
| Файл | `app/ui/static/js/tab_translation.js`, `app/ui/static/css/cards.css` |
| Уровень | Junior+ |
| Оценка | 260 LOC, 8 тестов |
| Зависит от | E2 (`stream.js`), C8 (`language.py` — индикатор конфликта) |
| Блокирует | приёмка вкладки «Перевод» |
| Пункт спеки | §14 «Вкладка 1 — Перевод», §4 «Определение языка» |

## Задача

Отрисовать ленту реплик. Макет задан спекой §14 дословно:

```
[00:05:32] Клиент · ES · открытый профиль
Bueno, eh, necesitamos revisar el contrato.

RU · черновик (0.9 с)          <- серым, замещается
RU · проверено (2.8 с)         <- финальный

Статус: STT ✓ | Перевод ✓
```

Модуль только представляет состояние из E2. Ни сетевых вызовов, ни
собственного состояния, ни логики вытеснения — она уже разобрана в E2 и
приходит готовыми полями.

Главное требование к внешнему виду вытекает не из эстетики: **черновик
быстрого трека и проверенный перевод должны различаться с одного взгляда**.
Пользователь произносит цифры вслух, глядя на экран; спутать 0.9-секундный
черновик с проверенным переводом — это озвученная клиенту неверная сумма.

## Интерфейс

```js
createCards({ container, stream, formatTime }) -> Cards

Cards.mount()      // подписки на stream, первичная отрисовка из getState()
Cards.unmount()
Cards.setFilter({ role: "all" | "meeting" | "microphone" })
Cards.scrollToLatest()
```

## Поведение

1. **Шапка карточки** — четыре элемента в порядке спеки: таймкод
   `[ЧЧ:ММ:СС]` от начала сессии, роль (`Клиент` / `Вы`), язык оригинала,
   профиль конфиденциальности на момент обработки. Профиль берётся из
   поля сегмента, а не из текущего состояния переключателя: он неизменяем
   и отражает фактические условия (§8.2).

2. **Тело карточки** — `rawText` как есть. Ни исправлений, ни
   капитализации, ни подсветки «странных» слов: это неизменяемый источник
   аудита (§8.1).

3. **Черновик быстрого трека:** серый цвет, курсив, метка «черновик» и
   задержка в секундах. При приходе точного перевода строка **заменяется**,
   а не дополняется: две строки перевода одновременно — прямой путь к
   тому, что человек прочитает не ту.

4. **Проверенный перевод:** основной цвет текста, метка «проверено» и
   фактическая задержка. Задержка показывается всегда, даже когда она
   вписалась в бюджет: это единственный способ заметить деградацию
   раньше, чем она станет мешать.

5. **Строка статуса:** `STT` и `Перевод` с тремя состояниями — ожидание,
   успех, ошибка. Ошибка перевода показывает код и кнопку повтора
   (обработчик — E7, история сессий), а не молчит.

6. **Индикатор конфликта языков** (§4, C8): при `conflict: true` рядом с
   языком оригинала — значок и подсказка с текстом `note` из
   `LanguageDecision` (он уже на русском и человекочитаемый). Перевод при
   этом идёт по **заданному** языку; интерфейс не предлагает «исправить»
   язык одним нажатием — автопереключение запрещено спекой.

7. **Автопрокрутка с прилипанием.** Лента прокручивается к новой реплике,
   только если пользователь находится внизу. Прокрутил вверх читать —
   прокрутка замирает и появляется кнопка «Новые реплики (N)». Иначе
   читать предыдущий фрагмент во время встречи физически невозможно.

8. **Вытесненные и «сироты».** Элементы с `superseded: true` не
   отрисовываются. Элементы с `orphan: true` остаются серыми с пометкой
   «не подтверждён точным треком» — пользователь помнит фразу, и её
   исчезновение вызывает больше вопросов, чем пометка.

9. **Обновление точечное.** Приход перевода перерисовывает одну карточку,
   не ленту. Час встречи — это сотни карточек; полная перерисовка на
   каждое событие даст видимые подвисания.

10. **Ноль констант в модуле.** Пороги задержек, цвета статусов, формат
    таймкода — из общего файла темы и из конфига, отданного сервером
    (§14: «UI не содержит собственных констант»).

## Запрещено

- Показывать черновик и проверенный перевод одновременно.
- Править `rawText` при отрисовке (регистр, пунктуация, обрезка).
- Брать профиль конфиденциальности из текущего переключателя, а не из
  поля сегмента.
- Отрисовывать вытесненные сегменты.
- Предлагать автоматическое переключение языка при конфликте.
- Прокручивать ленту, когда пользователь читает выше.
- Хранить состояние в модуле или ходить в сеть: источник один — E2.
- Скрывать ошибку перевода: пустая карточка без пометки читается как
  «перевода не было», а не как «перевод упал».
- Копировать текст в буфер обмена из этого модуля: доставка — G3, по
  явному действию.

## Критерии приёмки

- [ ] Шапка содержит таймкод, роль, язык, профиль в порядке §14
- [ ] Профиль в карточке не меняется после переключения профиля в панели
- [ ] Черновик отрисован серым курсивом с меткой и задержкой
- [ ] Приход точного перевода **заменяет** черновик; двух строк перевода
      одновременно не бывает ни в один момент
- [ ] `superseded: true` → карточка отсутствует в DOM
- [ ] `orphan: true` → карточка серая с пометкой, не удалена
- [ ] `conflict: true` → значок и подсказка с текстом `note`, кнопки
      «переключить язык» нет
- [ ] Ошибка перевода → код ошибки и кнопка повтора видимы
- [ ] Пользователь внизу ленты → автопрокрутка; прокрутил вверх →
      прокрутка остановлена, счётчик новых растёт
- [ ] Приход перевода перерисовывает одну карточку (проверяется счётчиком
      операций DOM)
- [ ] `unmount()` снимает все подписки; повторный вызов безопасен
- [ ] В модуле нет числовых литералов порогов и цветовых констант
      (проверяется грепом)

## Подсказки

Разметка карточки:

```html
<article class="card" data-segment-id="...">
  <header>
    <time>[00:05:32]</time>
    <span class="role">Клиент</span>
    <span class="lang" data-conflict="false">ES</span>
    <span class="profile profile--open">открытый профиль</span>
  </header>
  <p class="raw"> … </p>
  <p class="translation translation--draft">RU · черновик (0.9 с)</p>
  <footer class="status">STT ✓ | Перевод ✓</footer>
</article>
```

Прилипание к низу:

```js
const atBottom = el.scrollHeight - el.scrollTop - el.clientHeight < 40;
```

Ловушки:
- различие черновика и финала только цветом не работает: на проекторе и
  при демонстрации экрана серый и чёрный сливаются — курсив и текстовая
  метка обязательны;
- таймкод считается от начала сессии в миллисекундах (`INTERFACES.md`
  §0), а не от системного времени: форматирование через `Date` даст
  смещение на часовой пояс;
- `role` в данных — `"meeting"` / `"microphone"`, в интерфейсе —
  «Клиент» / «Вы»; словарь подписей держать в одном месте вместе с
  остальной локализацией;
- при быстрой речи карточки приходят чаще, чем кадр отрисовки —
  накопление изменений и применение через `requestAnimationFrame` снимает
  дёрганье ленты.
