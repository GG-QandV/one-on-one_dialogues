## Задача

Превратить сырой JSON от `whisper-cli -oj` в типизированный `Transcript`.
Это единственное место в проекте, которое знает формат вывода whisper: все
остальные модули работают с `Transcript`, а не с `payload`. Формат вывода
whisper.cpp менялся между версиями и будет меняться дальше — изоляция здесь
означает, что смена версии затронет один файл.

Отдельная ответственность — `stt_confidence`. Владелец подтвердил (ответ Q5),
что уверенность нужна и для логики, и для аудита. whisper не отдаёт готовое
число: считается усреднённая логарифмическая вероятность токенов.

## Интерфейс

```python
@dataclass(frozen=True, slots=True)
class Word:
    text: str
    t_start_ms: int
    t_end_ms: int
    probability: float | None      # 0..1, None если whisper не дал

@dataclass(frozen=True, slots=True)
class Transcript:
    text: str                      # склеенный текст, нормализованные пробелы
    detected_language: str | None  # ISO 639-1, нижний регистр
    confidence: float | None       # усреднённый avg_logprob, см. §Поведение
    words: tuple[Word, ...]        # пустой кортеж допустим

def parse(raw: WhisperRawResult) -> Transcript
```

## Поведение

1. **Текст.** Склеить `text` всех элементов `transcription`, схлопнуть
   повторяющиеся пробелы, обрезать края. Пустой результат — это валидный
   `Transcript` с `text=""`, а не исключение: whisper на тишине возвращает
   пустоту законно.

2. **Служебные вставки удалить.** whisper вставляет маркеры вида
   `[BLANK_AUDIO]`, `[_BEG_]`, `(музыка)`, `[Music]`, `[silence]`. Удалять
   по списку паттернов, список — константа модуля, регистронезависимо.
   После удаления повторно схлопнуть пробелы.

3. **Язык.** Брать из `result.language` верхнего уровня, привести к нижнему
   регистру. Значения `"auto"`, `""`, отсутствие ключа → `None`.

4. **Confidence.** Порядок попыток, первая успешная выигрывает:
   - если у сегментов есть поле `avg_logprob` — усреднить по сегментам,
     взвесив длительностью сегмента;
   - если есть `tokens[].p` или `tokens[].plog` — усреднить по токенам,
     исключив служебные токены (начинаются с `[_` или `<|`);
   - иначе `None`.

   Возвращать **сырое усреднённое значение avg_logprob** (отрицательное
   число, обычно −0.1…−1.5), не преобразовывать в проценты. Интерпретацию
   делает потребитель; преобразование здесь потеряло бы информацию.

5. **Слова.** Заполнять `words`, только если whisper дал пословные
   таймкоды. Отсутствие — не ошибка: пустой кортеж. Таймкоды whisper —
   в сотых долях секунды (`offsets` в миллисекундах, `timestamps` в строках
   `00:00:01,234`); нормализовать в миллисекунды от начала **сегмента**,
   не от начала сессии.

6. **Устойчивость к формату.** Отсутствие необязательного ключа —
   не исключение. `SttOutputMalformed` бросается только если отсутствует
   сам массив `transcription` или он не список.

7. **Никаких сетевых вызовов и обращений к БД.** Функция чистая.

## Запрещено

- Модифицировать текст сверх удаления служебных маркеров и пробелов:
  никакой капитализации, пунктуации, коррекции — это исказит `raw_text`,
  который по спеке неизменяем и является источником аудита.
- Отбрасывать сегмент из-за низкой уверенности: фильтрация — не здесь.
- Обращаться к `raw.payload` из других модулей (проверяется грепом в ревью).
- Преобразовывать `avg_logprob` в проценты или «звёздочки».
- Возвращать `confidence=0.0` вместо `None` при отсутствии данных: ноль —
  это валидное значение логарифмической вероятности, оно означает
  уверенность 100%, а не «нет данных».

## Критерии приёмки

- [ ] Полный JSON whisper с сегментами и `avg_logprob` → корректные
      `text`, `detected_language`, `confidence`
- [ ] JSON без `avg_logprob`, но с токенами → confidence посчитан по токенам
- [ ] JSON без того и другого → `confidence is None`
- [ ] `[BLANK_AUDIO]`, `[Music]`, `(музыка)` удалены, пробелы схлопнуты
- [ ] Пустая транскрипция → `Transcript(text="")`, без исключения
- [ ] `language: "auto"` → `None`
- [ ] Отсутствие ключа `transcription` → `SttOutputMalformed`
- [ ] Пословные таймкоды нормализованы в мс от начала сегмента
- [ ] Взвешивание confidence по длительности проверено на двух сегментах
      разной длины с разным avg_logprob
- [ ] Функция не делает ввода-вывода (проверяется отсутствием импортов
      `asyncio`, `sqlite3`, `httpx`)

## Подсказки

Типичный вывод `whisper-cli -oj` (структура может отличаться версией —
писать защитно):

```json
{
  "systeminfo": "...",
  "model": {"type": "base", "multilingual": true},
  "params": {"language": "auto"},
  "result": {"language": "ru"},
  "transcription": [
    {
      "timestamps": {"from": "00:00:00,000", "to": "00:00:02,340"},
      "offsets": {"from": 0, "to": 2340},
      "text": " Нам нужно проверить договор.",
      "tokens": [
        {"text": "[_BEG_]", "timestamps": {...}, "p": 0.98},
        {"text": " Нам", "offsets": {"from": 0, "to": 320}, "p": 0.91}
      ]
    }
  ]
}
```

Ловушки:
- текст сегментов приходит с ведущим пробелом — это норма, обрезать;
- поле `p` — вероятность (0..1), поле `plog` — логарифм; не путать;
- `offsets` уже в миллисекундах, `timestamps` — строки, парсить не нужно,
  если `offsets` присутствуют;
- при `-l auto` ключ `result.language` появляется, при явном языке может
  дублировать заданный — это не конфликт, конфликтом занимается C8.
