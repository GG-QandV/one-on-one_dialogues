## Задача

Хранить ключи провайдеров, введённые пользователем, **только в
оперативной памяти процесса**, с TTL 60 минут и кнопкой немедленного
отзыва.

Спека §16 перечисляет запреты прямо: SQLite, файлы, URL, localStorage,
cookies, аналитика, трейсы исключений, access- и debug-логи. Запись
ключа куда-либо, кроме памяти этого объекта, — блокирующий дефект
(`INTERFACES.md` §6.4).

`get()` — это и есть `key_provider`, который получают все провайдеры
(D1 п. 2). Больше никто ключи не видит.

**Порядок работ.** Контракт не берётся в работу, пока G1 не подключён к
логгерам и его приёмка не пройдена: первый же тест с настоящим ключом
без редактора пишет ключ в файл лога.

## Интерфейс

```python
@dataclass(frozen=True, slots=True)
class KeyStoreConfig:
    ttl_s: float = 3600.0              # 60 минут по спеке §16
    warn_before_s: float = 300.0       # предупредить UI за 5 минут

class KeyStore:
    def __init__(self, config: KeyStoreConfig | None = None,
                 *, redactor: LogRedactor | None = None,
                 clock: Callable[[], float] = time.monotonic) -> None: ...

    def put(self, provider: str, key: str) -> None: ...
    def get(self, provider: str) -> str: ...        # ProviderAuthError
    def revoke(self, provider: str | None = None) -> None: ...   # None = все
    def has(self, provider: str) -> bool: ...
    def masked(self, provider: str) -> str: ...     # "sk-…XYZ" для UI
    def expires_in_s(self, provider: str) -> float | None: ...
    def snapshot(self) -> dict: ...    # наличие и TTL, без ключей
```

## Поведение

1. **Только память.** Ни `db.write`, ни файлов, ни переменных окружения,
   ни временных директорий. Единственное место хранения — приватный
   словарь экземпляра.

2. **TTL проверяется при чтении, а не таймером.** `get()` на просроченный
   ключ удаляет запись и бросает `ProviderAuthError`. Фоновая уборка
   допустима как дополнение (для честного `snapshot()`), но не как
   единственный механизм: остановленный таймер не должен продлевать жизнь
   ключа.

3. **`put` регистрирует литерал в `LogRedactor`** (G1 `add_literal`),
   `revoke` — снимает (`remove_literal`). Это единственная связь модуля с
   внешним миром, и она обязательна: паттерны редактора покрывают
   известные формы ключей, литерал — все остальные.

4. **`put` перезаписывает** ключ того же провайдера и **сбрасывает TTL**.
   Старый литерал снимается из редактора, новый регистрируется.

5. **Пустой ключ или строка из пробелов** → `ProviderAuthError` на этапе
   `put`, запись не создаётся. Это ловит «пользователь нажал сохранить с
   пустым полем» до первого сетевого вызова.

6. **`masked`** показывает не более 4 последних символов и префикс до
   первого дефиса, если он есть: `sk-…f12a`. Для ключей короче 8 символов
   — только маска, без хвоста. Маска — единственная форма, в которой ключ
   покидает объект, кроме `get()`.

7. **`revoke(None)`** очищает всё и снимает все литералы. Это кнопка
   «Revoke» из спеки §16; она обязана работать мгновенно и не зависеть от
   состояния сетевых вызовов.

8. **`snapshot()`** содержит: список провайдеров, флаг наличия ключа,
   секунды до истечения, флаг `expiring_soon` (меньше `warn_before_s`).
   Ни ключей, ни масок, ни длин.

9. **`repr` и `str` объекта** не содержат ни ключей, ни имён провайдеров
   с ключами. Переопределить явно, не полагаться на dataclass-поведение.

10. **Объект не сериализуется.** `__getstate__` бросает
    `InvariantViolation`: попытка положить `KeyStore` в pickle, в кэш или
    в снапшот состояния очереди — это запись ключа на диск окольным
    путём.

11. **Честность формулировок (спека §16, строка про README).** Модуль
    обеспечивает отсутствие записи на диск и автоудаление по TTL. Он
    **не** обеспечивает невозможность доступа к ключу из самого процесса —
    ключ лежит в памяти в открытом виде, и в Python его нельзя надёжно
    затереть: строки неизменяемы, копии остаются в интернировании и в
    буферах HTTP-клиента. Это ограничение фиксируется в README и в
    docstring класса, а не замалчивается.

## Запрещено

- Писать ключ в БД, файл, лог, переменную окружения, URL, заголовок
  ответа UI, снапшот состояния.
- Отдавать ключ в `snapshot()`, `repr`, `str`, в текст исключения.
- Передавать ключ в конструктор провайдера: провайдеры получают
  `key_provider` (callable), а не значение (D1 п. 2).
- Кэшировать ключ на стороне провайдера или в замыкании дольше одного
  вызова.
- Продлевать TTL при использовании ключа: 60 минут отсчитываются от
  `put`, а не от последнего `get`. Иначе активная сессия держит ключ
  бесконечно.
- Реализовывать «запомнить ключ» и любую форму персистентности — это не
  тир 2, это прямой запрет §16.
- Обещать в UI или README, что ключ недоступен серверу.
- Начинать работу до приёмки G1.

## Критерии приёмки

- [ ] `put` + `get` возвращает исходный ключ
- [ ] `get` через `ttl_s + 1` модельной секунды → `ProviderAuthError`,
      запись удалена
- [ ] `get` на неизвестного провайдера → `ProviderAuthError`
- [ ] TTL не продлевается многократными `get` (после `ttl_s` ключ мёртв
      независимо от числа обращений)
- [ ] `put` того же провайдера сбрасывает TTL и заменяет значение
- [ ] Пустой ключ и ключ из пробелов → `ProviderAuthError`, `has()`
      остаётся `False`
- [ ] `revoke("gemini")` не затрагивает `claude`
- [ ] `revoke(None)` очищает всё
- [ ] `put` вызывает `redactor.add_literal`, `revoke` —
      `remove_literal` (проверяется подменённым редактором)
- [ ] `masked("sk-CANARY-12345")` не содержит середины ключа
- [ ] Ключ `sk-CANARY-12345` не встречается в `repr()`, `str()`,
      `snapshot()` и в тексте любого возбуждаемого исключения
- [ ] `pickle.dumps(store)` → `InvariantViolation`
- [ ] Грep по всем файлам, созданным процессом за тест (лог, БД, temp),
      не находит `sk-CANARY-12345`

## Подсказки

Интеграция с провайдером — через связывание, не через значение:

```python
provider = GeminiTextProvider(
    config=cfg, privacy=privacy,
    key_provider=lambda: store.get("gemini"),
)
```

Замыкание вызывает `get()` в момент сетевого вызова: истёкший ключ даёт
`ProviderAuthError` там же, где обрабатываются остальные ошибки
провайдера, и `OfflineGate` (D7) переводит его в `BLOCKED` без счётчика.

Ловушки:
- `time.monotonic` обязателен: на `time.time` перевод системного времени
  назад продлевает жизнь ключа;
- TTL 60 минут против встречи на 90 минут — штатная ситуация: UI обязан
  показать предупреждение за `warn_before_s` и дать повторный ввод, иначе
  перевод молча отвалится на середине переговоров;
- при работе через systemd `EnvironmentFile` (локальный режим, §16) ключ
  приходит из окружения при старте — его тоже нужно положить через `put`,
  чтобы он попал в редактор, а не читать `os.environ` напрямую в
  провайдере;
- тест «грep по файлам» — не формальность: именно он ловит запись ключа
  через неожиданный путь вроде трейса в файле лога или дампа состояния
  очереди.
