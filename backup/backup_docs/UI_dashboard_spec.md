# Web UI — дашборд (из спеки §14)

Адрес: `http://127.0.0.1:8790`

## Постоянная верхняя панель (topbar)

- Индикатор профиля конфиденциальности — крупный, переключатель в одно действие
- Статус: Готов / Слушаю / Транскрибирую / Облако недоступно / Degraded
- Активный поток, языки, режим перевода
- Выбранный раздел библиотеки фактов
- Кнопки: Старт / Пауза / Завершить / Экспорт

## Вкладка 1 — «Перевод»

Живая лента: таймкод, роль (Клиент/Вы), язык, профиль.
Быстрый трек — серым, метка «черновик». Точный трек замещает, метка «проверено».

## Вкладка 2 — «Черновики ответов»

Карточка на вопрос клиента: русский черновик + перевод, источники из библиотеки, метка `has_gaps` при нехватке фактов, кнопка «Копировать». Автокопирования нет.

## Вкладка 3 — «Диагностика»

PipeWire-узел, уровень сигнала, VAD, очередь STT, задержка треков, RAM относительно порогов (high_mb/max_mb), деградация, провайдеры.

## Настройки (панель, оверлей)

Провайдеры, модели, ключи (маска, password, не в DOM), узлы PipeWire, языки, retention, VAD, контекст, библиотека фактов, профиль.

## История сессий

Список прошлых сессий, просмотр, ручной повтор перевода, экспорт (TXT/JSON/SRT/VTT).

## Экспорт

- TXT — исходный + перевод, только точный трек
- SRT/VTT — субтитры с таймкодами
- JSON — полный audit: raw_text, переводы, edit_log, privacy_profile, черновики, ошибки
