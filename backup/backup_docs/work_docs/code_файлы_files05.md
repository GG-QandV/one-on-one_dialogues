### Оговорка по цене решения (достоверность 70%)

800 мс — нижняя граница диапазона. Пауза внутри фразы длиннее 800 мс теперь разрежет реплику на два сегмента. Практически это заметно на речи с раздумьями («так… нам нужно… примерно тридцать тысяч») — вместо одной карточки будет две-три.

Смягчается двумя способами, оба уже в коде: окно контекста передаёт предыдущие сегменты переводчику, так что связность не теряется; порог остаётся настраиваемым из панели. Если на живых тестах дробление окажется мешающим — поднимаете до 900–1000, но тогда в бюджет нужно возвращать запас за счёт более быстрой модели перевода.
