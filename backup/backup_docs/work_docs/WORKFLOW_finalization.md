# Финализация speech-local: воркфлоу до живых тестов, без долгов

Документ построен на чтении запушенного кода репозитория, не на отчётах.
Цель — довести проект до первого живого теста ядра (захват → STT →
перевод → карточка) без хвостов и без скрытых долгов. Порядок фаз —
топологический: каждая фаза разблокирует следующую.

Правило всего документа: **репозиторий авторитетнее любого отчёта.**
«Тесты зелёные» не равно «код соответствует контракту» — это уже
подтверждено на `base.py`, где 161 зелёный тест сосуществовал с шестью
нарушениями контракта D1.

## Фаза 1. Ремонт `base.py` — снимает BLOCKER волны 1

`base.py` реализован с шестью отклонениями от D1 (см. отдельное задание
`TASK_fix_base_D1.md`). Из них дефект 3 (сигнатура `_parse`) —
блокирующий: D2/D3 по контракту не соберутся.

**Развилка fence, теперь решённая по коду.** `privacy.py` (прочитан)
даёт `require(cap) -> Fence` и `validate(fence, cap)`. Протокол
`TranslationProvider.translate(req, *, fence)` принимает fence снаружи.
Значит:

- `require()` вызывает **не провайдер**, а обработчик `JobType.TRANSLATE`
  (в `main.py`/queue), до постановки задачи;
- провайдер получает готовый `fence`, делает `_call`, затем
  `validate(fence, TEXT_TO_CLOUD)` **после** `_call`, до возврата;
- это ровно протокол из `INTERFACES.md §1.3` (require → call → validate →
  write). Провайдер отвечает за шаги call и validate, вызывающий — за
  require и write.

Порядок ремонта — три шага из `TASK_fix_base_D1.md`, шаг 3 обязателен.
Выход фазы: `base.py` проходит 11 критериев приёмки D1 **собственными
тестами** (сейчас их нет — дописать).

**Критерий завершения фазы 1:**

- `_parse(self, req, raw)` — сигнатура исправлена;
- `validate` стоит после `_call`;
- исключения из `errors.py` (`PrivacyViolation`, `StaleGenerationError`,
  `ProviderAuthError`, `ProviderUnavailable`), не `PermissionError`;
- `_classify` реализован по таблице кодов;
- таймаут через `asyncio.wait_for`;
- аудит не пропускается при `auditor is None` (отложенный импорт);
- 11 тестов D1 написаны и зелёные, включая тест switch-во-время-`_call`.
