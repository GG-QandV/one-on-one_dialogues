# E7 — панель настроек

| | |
| :-- | :-- |
| Файл | `app/ui/static/js/settings.js` |
| Уровень | Middle |
| Оценка | 280 LOC, 10 тестов |
| Зависит от | E2 (`stream.js`), E1-routes, G2 (BYOK), I1 (библиотека) |
| Блокирует | живой тест: ввод ключа и раздел библиотеки — предусловия любого прогона |
| Пункт спеки | §16 (BYOK), §12 (библиотека), §19 (конфиг), §4 (языки) |

## Задача

Панель, где пользователь **готовит** систему к встрече: вводит ключ
провайдера, выбирает провайдера и модель, задаёт языки потоков,
редактирует библиотеку фактов, меняет пороги.

Панель касается двух чувствительных вещей — ключа и библиотеки, — и обе
требуют дисциплины, которой нет в остальном UI. Ключ нельзя показывать,
логировать, класть в DOM-атрибут. Библиотеку нельзя незаметно
нормализовать (это обнуляет кэш префикса, I1) и нельзя сохранить сверх
лимита токенов молча.

Панель не ведёт состояния сессии — она пишет настройки на сервер и
показывает их текущие значения из снапшота.

## Интерфейс

```js
createSettings({ container, stream, commands }) -> Settings

Settings.mount()
Settings.unmount()

// commands — обёртка над POST-роутами E1:
commands.putKey(provider, key) -> Promise<{ masked, expires_in_s }>
commands.revokeKey(provider?) -> Promise<void>
commands.setProvider(name, model) -> Promise<void>
commands.setLanguages({ microphone, meeting }) -> Promise<void>
commands.upsertLibrary(name, domain, text) -> Promise<{ id, token_estimate }>
commands.deleteLibrary(id) -> Promise<void>
commands.selectLibrary(id) -> Promise<void>
commands.listLibrary() -> Promise<Array<{ id, name, token_estimate }>>
commands.getLibrary(id) -> Promise<{ id, name, domain, content_text }>
```

## Поведение

### Ключи (BYOK)

1. **Ключ вводится, но не отображается.** Поле ввода — типа `password`.
   После сохранения поле очищается, показывается **маска** из ответа
   сервера (`masked`, вида `sk-…f12a`) и оставшийся TTL. Введённое
   значение в JS-состоянии не хранится после отправки.

2. **TTL виден и живой.** `expires_in_s` из ответа отсчитывается на
   клиенте; при приближении к нулю (порог из конфига) — предупреждение
   «ключ истекает, встреча может прерваться». Событие обновления TTL,
   если сервер шлёт, — приоритетнее клиентского отсчёта.

3. **Revoke мгновенный.** Кнопка отзыва вызывает `revokeKey`, поле и
   маска очищаются немедленно, не дожидаясь подтверждения: отзыв не может
   «не сработать» на стороне UI.

4. **Ключ не попадает в DOM и логи.** Ни в `data-`-атрибуты, ни в
   `value` после отправки, ни в `console`. Маска — единственная форма в
   разметке.

### Провайдер и модель

5. **Список провайдеров и моделей — из снапшота/конфига**, не
   захардкожен. Выбор шлёт `setProvider`. Смена провайдера в активной
   сессии допустима (спека §9: взаимозаменяемость), но требует, чтобы
   ключ выбранного провайдера был введён — иначе перевод отвалится на
   первом сегменте. Предупредить, если ключа нет.

### Языки

6. **Языки потоков** (микрофон, собеседник) — из списка §4
   (`en/es/ru/uk/pl`) плюс `auto`. Выбор `uk`/`pl` как **цели** перевода
   помечается «тир 2, только текстовые модели» (не блокирует, но
   предупреждает). Направление перевода строится из пары языков; сама
   панель его не вычисляет — показывает выбор, решение за слоем перевода.

### Библиотека фактов

7. **Размер до сохранения.** При вводе/редактировании текста раздела
   показывается оценка токенов (из `upsertLibrary` или локальной
   прикидки) и лимит. Превышение лимита — сохранение **блокируется** с
   явным сообщением, а не обрезается (I1: молчаливое усечение запрещено).

8. **Текст не нормализуется в UI.** Введённый текст уходит на сервер как
   есть; нормализацию (BOM, CRLF) делает I1 один раз при записи. Панель
   не трогает переносы, регистр, пробелы — любая правка на клиенте
   разойдётся с тем, что сохранит сервер, и обнулит кэш префикса.

9. **Выбор активного раздела.** Один раздел привязывается к сессии
   (`selectLibrary`). Список показывает разделы с размером; полный текст
   грузится только по открытию раздела (`getLibrary`), не в списке (I1:
   `list()` не тянет тексты).

10. **Удаление с проверкой.** `deleteLibrary` может вернуть ошибку
    «раздел используется сессией» (I1). Показать её, не удалять из UI до
    подтверждения сервера.

### Общее

11. **Значения из снапшота.** При `mount()` панель заполняется текущими
    настройками из `/api/snapshot`: провайдер, языки, наличие ключа
    (маска, не сам ключ), список разделов. Не показывать пустую панель,
    пока снапшот грузится, — показать `loading`.

12. **Не ведёт состояния сессии.** Подписка на поток нужна только для
    TTL-события ключа и, возможно, статуса. Данные сегментов панель не
    читает.

## Запрещено

- Показывать ключ после ввода, класть его в DOM, в лог, в `console`.
- Хранить введённый ключ в JS-состоянии после отправки.
- Обрезать текст библиотеки под лимит.
- Нормализовать текст библиотеки на клиенте (переносы, регистр,
  пробелы).
- Тянуть полный текст всех разделов в список.
- Хардкодить список провайдеров, моделей, языков, пороги.
- Удалять раздел из UI до подтверждения сервера.
- Позволять сохранить раздел сверх лимита токенов.
- Показывать пустую панель во время загрузки снапшота.

## Критерии приёмки

- [ ] Поле ключа — `password`; после сохранения очищено, показана маска
- [ ] Введённый ключ отсутствует в DOM (`data-`, `value`) и в `console`
      после отправки
- [ ] TTL отсчитывается; у порога — предупреждение об истечении
- [ ] `revokeKey` очищает поле и маску немедленно
- [ ] Смена провайдера без введённого ключа → предупреждение
- [ ] `uk`/`pl` как цель → пометка «тир 2»
- [ ] Текст раздела сверх лимита → сохранение заблокировано, сообщение
      показано, обрезки нет
- [ ] Текст уходит на сервер без нормализации на клиенте (проверяется
      перехватом тела запроса: CRLF сохранён как есть)
- [ ] Список разделов не содержит полных текстов (проверяется, что
      `getLibrary` вызывается только по открытию)
- [ ] `deleteLibrary` с ошибкой «используется» → раздел остаётся в UI
- [ ] Панель заполняется из снапшота при `mount()`
- [ ] `unmount()` снимает подписки; повторный вызов безопасен

## Подсказки

Обработка ключа без утечки:

```js
async function saveKey(provider) {
  const key = keyInput.value;
  const res = await commands.putKey(provider, key);
  keyInput.value = '';                 // немедленно очистить
  showMask(res.masked, res.expires_in_s);
  // key больше нигде не хранится — вышел из области видимости
}
```

Ловушки:
- поле `password` не защищает от утечки в `data`-атрибут или в
  `console.log(key)` — запрет касается всего пути, не только видимости
  ввода;
- оценка токенов на клиенте (если делается для мгновенной обратной
  связи) — только для UI-подсказки; авторитетная оценка и блокировка —
  на сервере (I1), клиент не должен разрешить сохранение, которое сервер
  отклонит;
- `contenteditable` и rich-text для текста библиотеки запрещены: они
  вставляют HTML и невидимые символы, которые поедут в оценку токенов и
  в кэш; только `textarea` с plain text;
- маска ключа приходит с сервера (G2 `masked()`), не строится на
  клиенте: клиент не видит ключа целиком и не может замаскировать сам;
- смена языка потока во время активной сессии — вопрос к слою перевода
  (сменится ли направление на лету); панель только шлёт выбор, поведение
  фиксируется сервером, не здесь.
