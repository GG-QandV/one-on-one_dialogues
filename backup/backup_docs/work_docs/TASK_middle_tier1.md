# Задание Middle-агенту: все задачи тира 1 (кроме I2)

I2 (`provider.py`) отдан Senior — не трогать. Ниже — весь остальной
middle-объём: модули, UI, роуты, инфраструктура. Порядок внутри разделов —
по зависимостям; нарушение = переделка.

Процесс на каждый файл неизменен:
1. Прочитать контракт целиком, включая «Подсказки».
2. Выписать чекбоксы «Критериев приёмки» — это список тестов.
3. Тесты до кода.
4. Код.
5. `ruff` + `mypy --strict` + `pytest` (весь набор, не только свой).
6. Пройти «Запрещено» построчно.
7. PR: закрытые чекбоксы, незакрытые с причиной, **новое число тестов**.

Правило после E1: в отчёте называть прирост тестов («было N, стало M,
+K на этот модуль»), не «все проходят». «Tested implicitly» и «manual
inspection confirms» не принимаются — только явный тест.

## РАЗДЕЛ 1. Модули по волнам

### 1.1 D7 — `translation/offline.py` [сейчас]
Контракт `D7_offline.md`. Зависимости готовы (queue, db, base).
Ключевое:
- три состояния провайдеров (AVAILABLE/DEGRADED/BLOCKED), раздельно;
- `ProviderAuthError` → сразу BLOCKED, без счётчика;
- пробы half-open, экспоненциальный откат, **часы инъектируются**;
- `catch_up` ставит задачи хронологически, идемпотентно по `segment_id`;
- **не трогает STT** (§8.7), не делает сетевых вызовов;
- `snapshot()` без текста ошибок и без ключа.

### 1.2 I1 — `drafts/library.py` [сейчас]
Контракт `I1_drafts_library.md`. Миграция 003 применена.
Ключевое:
- оценка токенов эвристикой по доле кириллицы, без внешних токенизаторов;
- `upsert` сверх лимита → `LibraryTooLarge`, **не усечение**;
- текст нормализуется один раз при записи, при чтении **не трогается**;
- `list()` не тянет полные тексты;
- `delete` проверяет ссылки из сессий;
- ни сети, ни вызовов провайдеров.

### 1.3 G2 — `security/byok.py` [ТОЛЬКО после Senior-верификации G1]
Контракт `G2_byok_keystore.md`.
**Предусловие: Senior подтвердил, что G1 маскирует трейсы исключений**
(блок A6 верификации). Без этого не начинать — первый ключ утечёт.
Ключевое:
- только память, ни БД, ни файла, ни env;
- TTL от `put`, использование **не продлевает**;
- `put` регистрирует литерал в `LogRedactor`, `revoke` снимает;
- `get` — это `key_provider` для D2/D3;
- `__getstate__` бросает (запрет сериализации);
- ключ не в repr/snapshot/исключениях; тест канареечным `sk-CANARY`.

### 1.4 I3 — `drafts/trigger.py` [после волны 2]
Контракт `I3_drafts_trigger.md`. Зависит от parser (готов).
Ключевое:
- **правила, без модели и без LLM-вызова** — горячий путь;
- порог 0.5 из конфига, смещён в сторону срабатывания;
- языки en/es/ru/uk/pl из констант модуля;
- функция чистая, без состояния между вызовами;
- не запускать на исходящем потоке (микрофон).

### 1.5 F1 — `watchdog/memory.py` [после волны 2]
Контракт `F1_watchdog_memory.md`. Зависит от degradation (готов).
Ключевое:
- источник: cgroup v2 → v1 → vmrss, выбор один раз;
- **при vmrss суммировать дочерний whisper**, иначе память занижена;
- vmrss = деградированный источник → WARNING один раз + флаг в snapshot;
- `current_mb()` не делает I/O, не бросает (вызывается из тика каскада);
- без psutil, только /proc и cgroup;
- пороги из конфига, часы инъектируются.

## РАЗДЕЛ 2. UI-вкладки (контракты готовы, E1 готов)

**Инвариант всех вкладок** (нарушение = баг E2/E3): не ведут своего
состояния сегментов, подписываются через `stream.subscribe`, читают
`stream.getState()`, рисуют дельту. Логика — в E2 (`stream.js`). Образец —
`tab_translation.js` (E3, готов).

### 2.1 topbar — `topbar.js` (E6) [сейчас — высокий приоритет]
Контракт `E6_topbar.md`.
Ключевое:
- профиль переключается **по событию `privacy.changed`**, не по ответу
  POST; до события новый профиль не показывать активным;
- при ошибке/таймауте — откат в прежний профиль, видимая ошибка;
- индикатор языка + конфликт (C8), без кнопки «переключить язык»;
- «облако недоступно» и «нет связи с UI-сервером» — **разные**
  индикаторы;
- профиль по умолчанию из снапшота, не хардкод.

### 2.2 settings — `settings.js` (E7) [сейчас — высокий приоритет]
Контракт `E7_settings.md`. Зависит от роутов key/library (раздел 3).
Ключевое:
- поле ключа `password`, после отправки очищено, показана **маска**;
- ключ **не в DOM, не в console, не в JS-состоянии** после отправки;
- текст библиотеки **не нормализовать на клиенте** (обнуляет кэш);
- сверх лимита токенов → сохранение блокируется, не обрезка;
- список разделов без полных текстов;
- только `textarea` plain text, не contenteditable.

### 2.3 diagnostics — `tab_diagnostics.js` (E5) [сейчас]
Контракт `E5_tab_diagnostics.md`.
Ключевое:
- только отображает `snapshot()` модулей, ничего не вычисляет;
- vmrss-источник показывается с предупреждением о занижении;
- аудио-уровни — **живой индикатор** обоих потоков (отладка PipeWire);
- ключ/маску не показывать (это E7), только наличие + TTL;
- код ошибки провайдера без текста;
- опрос не чаще интервала из конфига, `unmount` гасит таймер.

### 2.4 tab_drafts — `tab_drafts.js` (E4) [после I2 (senior) и I1]
Контракт `E4_tab_drafts.md`. Ждёт I2 (генератор) и I1 (библиотека).
Ключевое:
- **нет автокопирования** — только по клику (§21.11);
- `has_gaps` виден явно, не спрятан;
- `sources` показаны; пустой sources без пробелов → предупреждение;
- статус «скопировано» только при `copyDraft → true`;
- перевод не прошёл проверку (нет `draft_translated`) → кнопка перевода
  неактивна, русский доступен;
- копирование только через G3 (`commands.copyDraft`).

### 2.5 history — `history.js` (E8) [после G4-роута экспорта]
Контракт `E8_history.md`. Зависит от роута экспорта.
Ключевое:
- экспорт **серверный** (`exportSession`), клиент не собирает форматы
  сам (иначе в выгрузку попадёт быстрый трек);
- четыре формата (txt/json/srt/vtt), файл приходит Blob;
- имя файла осмысленное (заголовок+дата), не `export.txt`;
- пагинация по `before`, не грузить все сессии;
- `URL.revokeObjectURL` после скачивания.

## Границы (для всех задач)

- I2 не трогать — Senior.
- Верификацию и аудит не делать — Senior. Свой модуль сам не «проверяю
  чтением», пишу тест.
- Роуты — с модулем, не заглушкой. Разрыв документировать комментарием.
- Формат событий и роутов — §7.1 и контракты вкладок дословно.
- Пороги, языки, лимиты — из конфига, не литералы.
- Секреты (ключ, библиотека, текст сегментов) — не в логах INFO+, не в
  DOM, не в исключениях.
- В отчёте — число тестов с приростом, не «все проходят».

## Если не сходится — спросить

- контракт против спеки или другого контракта;
- поведение недостижимо без смены сигнатуры;
- критерий приёмки непонятно как протестировать;
- модуль вырос в полтора раза от оценки LOC;
- роут вкладки требует данных, которых нет в снапшоте/событиях
  (gap E1/E2 — зафиксировать, не выдумывать).
