Решения в этих двух

Где	Решение	Обоснование
B1	validate возвращает список проблем и не бросает; бросает только load	Панель показывает пользователю все ошибки разом, а не первую
B1	Незнакомые секции и ключи при update переносятся в новый файл	Иначе панель вычистит параметры, добавленные будущей версией
B1	Комментарии исходного файла не сохраняются	Требует потокового TOML-редактора; вместо этого to_toml пишет свои подсказки к секциям
B1	Hot reload не реализуется	Тихая смена порогов посреди встречи хуже явного «примените после перезапуска»
B3	Даты остаются str ISO-8601, а не datetime	Обратная запись datetime порождает вопросы часового пояса; разбор — задача отображения
B3	Неизвестный статус и битый JSON не бросают, а пишутся в *_raw / *_malformed	Данные в БД старше кода — штатная ситуация при откате версии; история не должна падать на чтении
B3	Обратного преобразования (to_row) нет	Универсальный сериализатор в БД — прямой путь обхода инвариантов §8
