### Два senior-решения, требующие вашего ревью

**1. Обрезка хвостовой тишины — выигрыш в бюджете задержки.**

Сегмент закрывается по паузе 1000 мс, и вся пауза лежала в буфере. Отправлять её в whisper — распознавать на секунду больше аудио в каждом сегменте.

|                               | До      | После       |
| ----------------------------- | ------- | ----------- |
| Длина сегмента (речь 2500 мс) | 3720 мс | **2920 мс** |
| Лишнего аудио в STT           | 33%     | 8%          |

Прямой вычет из R7 (риск выхода за 3000 мс). Параметр `tail_keep_ms = 200` в конфиге — резать вплотную нельзя, whisper теряет окончания слов.

**2. Отклонение от спеки §7: FFmpeg не в горячем пути.**

Спека предписывает нормализацию через FFmpeg. Реализовано иначе: `pw-record` конвертирует в 16 kHz mono s16le сам, FFmpeg остаётся резервным бэкендом. Минус один процесс на поток, минус 40–80 МБ RAM при двух потоках. По правилу 4 роадмапа отклонение не может быть молчаливым — либо утверждаете, либо возвращаю FFmpeg в основной путь.
