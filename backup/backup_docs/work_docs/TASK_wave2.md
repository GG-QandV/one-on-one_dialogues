# БЛОК B. Реализация волны 2 (Middle)

Стартует после чистого блока A (или с обходом веток, где дефект чинится).
Четыре модуля. Порядок внутри: G2 ждёт чистого G1; остальные независимы.

## B1. `translation/offline.py` (D7)

Контракт `D7_offline.md`. Состояние доступности провайдеров + догон
очереди. Ключевое:
- три состояния (AVAILABLE/DEGRADED/BLOCKED), раздельно по провайдерам;
- `ProviderAuthError` → сразу BLOCKED, без счётчика;
- пробы half-open с экспоненциальным откатом, часы инъектируются;
- `catch_up` ставит задачи в хронологическом порядке, идемпотентно;
- **не трогает STT** (инвариант §8.7), не делает сетевых вызовов.

Зависимости готовы: `queue.py`, `db.py` ✅.

## B2. `security/byok.py` (G2) — ТОЛЬКО после чистого G1

Контракт `G2_byok_keystore.md`. Ключи в RAM, TTL 60 мин. Ключевое:
- только память, ни БД, ни файла, ни env;
- TTL от `put`, использование НЕ продлевает;
- `put` регистрирует литерал в `LogRedactor` (G1), `revoke` снимает;
- `get` — это `key_provider` для провайдеров D2/D3;
- `__getstate__` бросает (запрет сериализации);
- честность README: ключ в памяти открыт, затереть в Python нельзя.

**Предусловие:** A6 подтвердил, что G1 маскирует трейсы. Иначе B2 не
стартует.

## B3. `drafts/library.py` (I1) — нужна миграция 003

Контракт `I1_drafts_library.md`. Библиотека фактов, лимит 30k токенов.
Ключевое:

- `upsert` сверх лимита → `LibraryTooLarge`, НЕ усечение;
- текст нормализуется один раз при записи, при чтении НЕ трогается
  (иначе обнуляется кэш префикса);
- `list()` не тянет полные тексты;
- `delete` проверяет ссылки из сессий.

**Предусловие:** миграция `003_draft_answers.sql` применена (готова).

## B4. `ui/server.py` + `routes.py` (E1)

Контракт `E1_ui_server.md`. SSE-сервер на 127.0.0.1:8790. Ключевое:
- формат событий §7.1 **дословно** (клиент E2 уже написан против него);
- `sequence` монотонный сквозной, в поле `id:`;
- `publish` не блокирует, переполнение очереди клиента → отброс старого;
- снапшот при reconnect, НЕ переигрывание истории;
- только `127.0.0.1`, иначе WARNING;
- `/health` всегда, `/ready` после инициализации.

**routes.py — предусловие всех вкладок.** Роуты для команд:
