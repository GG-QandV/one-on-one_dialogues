## Побочно найдено и исправлено при проверке

pyproject.toml
  — build-backend был битым ("setuptools.backends._legacy:_Backend", несуществующий
    модуль) — pip install -e . падал с ModuleNotFoundError. Исправлено на
    "setuptools.build_meta" + добавлен [tool.setuptools.packages.find] include=["app*"]
    (без него setuptools не мог однозначно определить пакет из-за scripts/, tests/,
    migrations/, CONTRACTS/, backup/ в корне). Проверено на Python 3.12 (требование
    проекта) — pip install -e ".[dev]" и все тесты проходят.
