| Зависит от | `app/stt/parser.py` (C6) |
| Блокирует | индикатор языка в UI (E3), выбор направления перевода |

## Задача

Пользователь задаёт язык потока в настройках; whisper при включённом
автодетекте возвращает свой вариант. Они расходятся регулярно: короткая
реплика, акцент, переключение языка собеседником посреди разговора.

Спека решает конфликт однозначно: **для перевода используется заданный
язык**, детектированный фиксируется и показывается индикатором,
автопереключение запрещено. Причина — предсказуемость: молчаливая смена
направления перевода посреди переговоров хуже, чем один плохо переведённый
сегмент.

## Интерфейс

```python
@dataclass(frozen=True, slots=True)
class LanguageDecision:
    effective: str          # что уходит в перевод — ВСЕГДА configured
    configured: str
    detected: str | None
    conflict: bool          # True → индикатор в UI
    note: str | None        # человекочитаемое пояснение для UI, RU

def resolve(configured: str,
            detected: str | None,
            autodetect_enabled: bool) -> LanguageDecision
```

## Поведение

1. **`effective` всегда равен `configured`.** Единственное исключение:
   `configured == "auto"` — тогда `effective = detected or "auto"`.

2. **Конфликт** фиксируется, когда все условия истинны:
   - `autodetect_enabled`;
   - `detected` не `None` и не пустой;
   - `configured != "auto"`;
   - нормализованные коды не совпадают.

3. **Нормализация перед сравнением.** Нижний регистр, отбросить регион
   (`en-US` → `en`, `pt_BR` → `pt`). Учесть известные синонимы:
   `iw`/`he`, `in`/`id`, `jw`/`jv`, `ua`/`uk` (whisper иногда отдаёт `ua`,
   стандарт ISO 639-1 — `uk`).

4. **Близкие языки не считать конфликтом молча.** Пары
   `ru`/`uk`, `ru`/`be`, `cs`/`sk`, `hr`/`sr`, `id`/`ms` дают `conflict=True`,
   но `note` содержит уточнение: «близкие языки, детект ненадёжен на
   коротких репликах». Это меняет тон предупреждения в UI, а не решение.

5. **`note` пишется по-русски**, кратко, без служебных кодов в скобках:
   «Задан английский, распознан испанский». Названия языков — из
   словаря-константы модуля; неизвестный код выводится как есть.

6. **Функция чистая.** Ни БД, ни ввода-вывода, ни логирования побочными
   эффектами.

## Запрещено

- Менять `effective` на `detected` при конфликте — прямое нарушение §4.
- Накапливать статистику и переключать язык «по большинству» — это
  автопереключение, запрещённое спекой.
- Бросать исключение при конфликте: конфликт — штатная ситуация.
- Возвращать `conflict=True`, если автодетект выключен: без автодетекта
  сравнивать не с чем.

## Критерии приёмки

- [ ] `configured="en", detected="en"` → `conflict=False`, `note is None`
- [ ] `configured="en", detected="es"` → `conflict=True`, `effective="en"`
- [ ] `configured="en", detected="en-US"` → `conflict=False` (нормализация)
- [ ] `configured="uk", detected="ua"` → `conflict=False` (синоним)
- [ ] `configured="ru", detected="uk"` → `conflict=True`, в `note` есть
      пометка о близких языках
- [ ] `autodetect_enabled=False, detected="es"` → `conflict=False`
- [ ] `configured="auto", detected="es"` → `effective="es"`, `conflict=False`
- [ ] `detected=None` → `conflict=False`, `effective=configured`
