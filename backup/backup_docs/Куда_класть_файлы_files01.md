### Senior-решения, которые стоит проревьюить отдельно

| Решение                                           | Обоснование                                                                                                              |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Инварианты дублированы триггерами SQL             | Прикладной слой — первый рубеж, триггеры — последний. Обход через ручной `sqlite3` не испортит `raw_text`                |
| Писатель — отдельный поток с очередью, не мьютекс | Даёт наблюдаемость глубины очереди, обратное давление (`WriterQueueFull`) и корректный дренаж при shutdown               |
| `isolation_level=None` + явный `BEGIN IMMEDIATE`  | Неявные транзакции `sqlite3` откладывают `BEGIN` до первой DML — между чтением и записью может вклиниться другой процесс |
| Fencing-токен вместо проверки профиля             | Закрывает гонку TOCTOU: между проверкой «профиль открыт» и фактической отправкой аудио проходит время                    |
| Инкремент поколения без единого `await`           | Гарантия критерия 7: новые отправки отсекаются мгновенно, не дожидаясь закрытия WebSocket                                |
| Аренда с истечением вместо флага `running`        | SIGKILL не оставляет задачу зависшей навсегда                                                                            |
| `_claim` идёт через writer, не через читателя     | Выборка и захват аренды должны быть в одной транзакции, иначе два воркера возьмут одну задачу                            |
| `LeaseLost` при `_complete`                       | Результат воркера с перехваченной арендой не навязывается                                                                |
